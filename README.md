# Explore Travel — Demo Homepage

Preview the static homepage locally by opening `index.html` in a browser, or run a simple local server:

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000
```

Files added:
- `index.html` — homepage
- `assets/css/styles.css` — styles
- `assets/js/main.js` — small interactions

Images use Unsplash placeholders; replace with your own high-quality photos.
